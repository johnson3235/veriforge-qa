# VeriForge QA

Independent QA automation studio website.

## Deploy on Vercel
Import `johnson3235/veriforge-qa` as a new Vercel project. Framework preset: Other. No build command required.

## Scope
Static responsive landing page with Playwright automation, API testing, quality audits and public technical portfolio.

Brand name is provisional. Portfolio repositories are technical samples, not commercial client case studies. Add verified contact details before promoting the site.
